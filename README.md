## Features

> `go install github.com/pardnchiu/go-rest-client/cmd/tui@latest` · [Documentation](./doc/doc.md)

- **VSCode .http Compatible** — Reuse VSCode REST Client request files as-is and run them straight from the terminal.
- **Hot Reload on Save** — Watches the `.http` file and re-parses it after a 200ms debounce, so the request list updates the moment you save while keeping your current selection.
- **Live SSE Streaming** — Detects `text/event-stream` responses and renders them line by line with a running event count, ideal for debugging LLM or push endpoints.
- **Readable Responses at a Glance** — Color-codes status by 2xx/3xx/4xx, pretty-prints JSON, and shows full headers alongside request duration.
- **Keyboard-Only Split Pane** — Request list on the left, details on the right; arrow keys and Tab cover browsing, sending, and switching.
